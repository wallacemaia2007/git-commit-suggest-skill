# Exemplos

## Inglês com separador em branco

```text
feat(ui): add mobile navigation menu

- Implement hamburger toggle for small screens
- Add slide-in animation for menu drawer
```

## Português com separador `dash`

```text
fix(form): corrige envio duplicado

-
- Desativa o botão durante o envio
- Impede cliques múltiplos
```

## Espanhol

```text
feat(ui): añade menú de navegación móvil

- Implementa el botón de menú para pantallas pequeñas
- Añade animación deslizante al menú
- Ajusta el encabezado para el nuevo menú
```

## Francês

```text
fix(auth): corrige l’expiration du jeton

- Met à jour le renouvellement du jeton
- Gère les sessions expirées
```

## Italiano

```text
feat(ui): migliora il menu di navigazione

- Aggiunge il pulsante per gli schermi piccoli
- Mantiene l’anteprima sincronizzata
```

## Alemão

```text
fix(auth): behebt den Ablauf des Sitzungstokens

- Aktualisiert die Token-Erneuerung
- Behandelt abgelaufene Sitzungen
```

## Breaking change

```text
refactor(api)!: remove legacy response format

- Replace the legacy response envelope
- Document the new API contract

BREAKING CHANGE: clients must read the new response fields
```
